# scoundrel-tui

A terminal-based implementation of the solo card game [Scoundrel](http://stfj.net/art/2011/Scoundrel.pdf).

## Installation

Install using Cargo:
```sh
cargo install --locked scoundrel-tui
```

Alternatively, build and run from source:
```sh
git clone https://github.com/adrior11/scoundrel-tui.git
cd scoundrel-tui
cargo run --release
```
